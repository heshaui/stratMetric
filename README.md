# 策研台个人试用版

当前版本的首页是短线市场雷达：读取全市场最近一个完整快照，展示市场温度、强势板块、最多三只明日重点候选、冲板观察、方向资讯和手动持仓计划。系统会保存每日候选，并在后续更新时补记 1、3、5 个观察日表现。

原有研究链路继续保留：更新真实日线、编辑动态策略规则、保存版本、运行确定性的日频回测，并查看指标、净值、回撤、持仓、成交、研究诊断和每日信号。

为保证当前环境零安装启动，0.1 版暂时使用 Node 内置服务承载本地接口与样例计算。策略、数据和结果已经按独立模块组织，后续引入 Python 计算服务时保持浏览器接口不变。

## 启动

```powershell
npm start
```

浏览器打开 `http://127.0.0.1:4173`。

## 当前数据

短线雷达默认覆盖沪深普通人民币股票，排除特定板块、风险标记证券、上市时间过短、成交额不足和难以正常成交的极端状态。板块与候选按量价、趋势、活跃度和相关公开资讯综合排序。首版以收盘后明日计划为主，交易时段内的状态确认将在下一阶段加入。

雷达在保存行情前会检查有效价格与成交数据。盘前或数据源异常导致新快照未就绪时，不覆盖已有缓存，自动使用最近一份有效数据，并在页面显示实际数据日期和回退原因。

首页可以保存个人资金方案和短线条件。当前默认按 27000 元资金、3 至 70 元股价、30 亿至 200 亿元流通市值、最多 3 只持仓计算，并按 100 股整数倍给出建议数量、占用金额、仓位比例和计划最大损失。

首页还提供单股分析：输入证券名称或代码后，系统会按同一份市场快照、方向热度和个人条件给出阶段结论、判断理由、计划条件、停止观察条件与建议数量。

配置 `OPENAI_API_KEY` 和 `OPENAI_BASE_URL` 后，更新雷达会先按固定条件生成最多 12 只合格候选，再由 AI 从候选池中选择和排序最多 3 只，并为每只补充入选理由。单股分析也会在固定规则结论之上增加 AI 研判。可通过 `OPENAI_MODEL` 指定模型；未指定时使用项目默认模型。雷达页顶部可以随时启用或禁用 AI 研判，关闭后雷达和单股分析只使用固定规则，开关状态会保存在本机；重新启用时会直接使用当前缓存行情恢复 AI 排序。AI 不能加入候选池之外的证券，也不能放宽资金、价格、市值等条件；调用失败时页面会明确显示本次沿用规则结果。

数据页可以按证券名称、代码或拼音首字母联想，并更新最多 40 只证券的真实前复权日线。当前缓存使用固定技术验证池，策略按趋势、稳定性和流动性在每个调仓日重新排序。模拟数据仍保留为离线后备。

每日信号页使用当前策略规则计算最新收盘后的目标名单，并与上次正式信号对照。未到策略设定的调整日时只显示观察预览，不生成新的成交安排。

结果页会根据市场阶段、回撤路径、证券贡献和交易成本生成可复核的研究诊断，并给出下一项单参数验证建议。诊断只解释当前历史结果，不会自动修改策略或触发新的运行。

当前真实数据版本尚未加入历史范围变化、现金分红和财务披露数据，因此页面会明确展示相应限制，结果不能直接作为投资结论。

## 项目结构

```text
public/             浏览器界面
server/             本地服务、存储和回测核心

data/               运行后生成的本地状态
docs/               产品执行文档
```
