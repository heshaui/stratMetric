## 当前交付目标

当前只建设个人试用版，默认由产品所有者本人在单机环境使用。当前首页优先建设短线市场雷达，原有研究能力作为验证与复盘工具。开发优先级如下：

1. 全市场收盘数据能够稳定更新并形成每日雷达。
2. 首页能够给出市场温度、强势方向和最多三只条件式候选。
3. 手动持仓能够得到继续持有、退出和做T条件。
4. 每日候选能够保存并追踪后续表现。
5. 策略、回测和诊断继续承担规则验证与历史复盘。

单股分析采用双层结果：固定规则提供可重复的筛选、资金和停止观察条件；AI 研判只解释证据包中的市场、方向、个股与资讯，并明确标注置信度和数据限制。

当前不建设订阅、额度、付款、成员协作、公开注册和运营后台。相关内容仅作为后续扩展草案，不影响个人试用版的技术与验收决策。

## 已确定的首版边界

- 市场：沪深市场普通人民币股票，暂不包含北交所、基金、债券和衍生品。
- 频率：日频选股及调仓。
- 方向：只做多，不使用融资融券。
- 运行方式：历史研究，不连接真实委托。
- 默认执行：交易日收盘后生成信号，下一个交易日开盘执行。
- 默认组合：最多 20 只股票，等权，单只目标权重不超过 10%。
- 默认费用：按日期生效的税费表，加双边佣金和滑点。
- 默认比较基准：沪深 300 全收益口径；可改为其他已接入基准。
- 默认年化无风险收益：2%。
- 默认数据区间：2015-01-01 起，结束日不晚于最近一个完整交易日。
- 结果要求：同一数据快照、协议版本和引擎版本必须得到一致结果。

## 决策状态

文档中的内容分为三类：

- **已确定**：首版按此实现。
- **可配置**：系统提供选项，但必须有明确默认值。
- **公开使用前确认**：涉及供应合同、展示范围或价格，个人试用阶段先按抽象接口完成。

## 变更规则

- 产品行为变化必须先更新相应文档，再进入开发。
- 计算公式、时间对齐或成交规则变化时，必须提升引擎版本。
- 策略字段含义或必填规则变化时，必须提升协议版本。
- 数据修订需要产生新的数据快照，不覆盖已经保存的研究记录。
