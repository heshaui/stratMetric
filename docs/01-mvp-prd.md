# 策研台 MVP 产品需求

版本：1.0  
状态：个人试用版开发基线  
适用范围：产品所有者单机试用

## 1. 产品目标

策研台帮助用户把投资想法整理成无歧义的策略规则，并基于可追溯的数据完成历史验证、结果解释和版本比较。

首版成功不以功能数量衡量，而以三件事衡量：

1. 新用户能在 15 分钟内完成一次有效研究。
2. 用户能够看懂策略实际执行了什么规则。
3. 相同输入能够稳定得到相同结果。

## 2. 目标用户与首要任务

| 用户 | 首要任务 | 首版提供的帮助 |
|---|---|---|
| 非技术投资者 | 把自然语言想法变成明确规则 | 引导补齐条件、表单确认、模板起步 |
| 量化入门用户 | 快速验证常见选股思路 | 指标库、历史验证、图表和明细 |
| 专业研究员 | 快速试验并比较多个版本 | 参数试验、版本差异、结果对比 |
| 小型研究团队 | 留存统一的研究过程 | 版本、备注、报告和运行记录 |

## 3. 核心对象

| 对象 | 定义 |
|---|---|
| 策略 | 一组可执行的选股、排序、调仓和仓位规则 |
| 策略版本 | 某一时刻冻结的完整策略规则，不允许原地修改 |
| 数据快照 | 一次运行引用的数据集合及其版本标识 |
| 回测任务 | 策略版本、数据快照、时间区间和运行参数的组合 |
| 回测结果 | 净值、指标、持仓、交易、诊断和运行记录 |
| 参数试验 | 对指定参数取多个值后形成的一组回测任务 |
| 报告 | 对一次或多次结果的固定格式展示文件 |

## 4. MVP 功能优先级

### 4.0 当前个人试用版

当前开发只包含以下能力：

- 单一默认工作区，不建设成员体系。
- 策略创建、结构化编辑、规则检查和版本保存。
- 单次日频回测、任务状态和失败原因。
- 核心指标、净值、回撤、持仓、成交和费用明细。
- 两个策略版本的结果比较。
- 本地数据快照和指标目录。
- 桌面浏览器完整可用，移动端保证能够查看结果但不作为首轮验收重点。

研究诊断、参数试验和 PDF 报告在核心回测稳定后加入。订阅、额度、付款、成员协作和公开运营均不属于当前范围。

### 4.1 P0：完整产品必需

#### 工作台框架

- 左侧一级导航：策略、回测任务、数据状态、报告、设置。
- 顶部显示当前工作区、数据日期和任务状态。
- 中间区域提供对话、规则、代码三个标签；首版代码标签只读，用于展示系统生成的逻辑摘要。
- 右侧固定显示策略摘要、时间区间、比较基准、费用方案和保存状态。

验收标准：

- 在 1440×900、1280×720 和 390×844 三种尺寸下完成主要流程。
- 页面刷新后能够回到最近一次打开的策略和标签。
- 任何未保存修改都必须有明显标识，离开前给出确认。

#### 策略创建

- 用户可以从空白输入、常用模板或复制已有策略开始。
- 研究助手必须补齐股票范围、指标条件、排序方式、持仓数量、调仓周期、仓位规则、费用方案、比较基准和时间区间。
- 信息不足时只提出对结果有实质影响的问题，每轮最多三个。
- 生成后先展示结构化规则，不直接启动回测。
- 用户确认规则后创建第一个策略版本。

验收标准：

- 输入“低估值、高盈利、近期走势较强，每月调整”时，系统能够形成完整但未确认的规则草案。
- 草案中的每个数值都能在规则表单中找到来源和修改入口。
- 未完成必填项时不能启动回测，并准确指出缺失项。

#### 结构化策略编辑器

- 分区：股票范围、可交易条件、筛选条件、排序、持仓、调仓、费用、比较基准。
- 每条条件支持字段、运算符、值、空值处理和生效日期。
- 多条条件首版只支持“全部满足”；复杂组合延后。
- 排序支持最多三个字段，并明确升序或降序。
- 修改规则后必须另存为新版本；历史版本保持不变。
- 展示易读的规则摘要和机器可执行的协议内容。

验收标准：

- 表单与协议内容双向一致。
- 任一字段修改后，规则摘要在 300 毫秒内更新。
- 保存前完成字段类型、取值范围、日期关系和逻辑完整性检查。

#### 规则检查

- 检查信息可用日期，避免引用当时尚不可知的数据。
- 检查财务披露时间、历史股票范围、价格状态和数据缺口。
- 检查持仓数量、行业上限和单只权重是否相互冲突。
- 检查时间区间内是否有足够的指标预热期。
- 检查比较基准是否覆盖完整研究区间。

检查结果分为：阻止运行、需要确认、信息提示。

#### 回测任务

- 支持创建、排队、运行、成功、失败、取消七种状态。
- 支持单次回测和单参数批量试验。
- 任务页面展示进度、当前阶段、预计剩余时间和失败原因。
- 失败任务可以在不改变输入的前提下重新运行。
- 完成后保存全部运行输入及版本标识。

验收标准：

- 用户重复点击运行不会创建重复任务。
- 取消后的任务不再占用计算资源，已写入的临时结果不作为正式结果展示。
- 失败信息使用用户可理解的语言，同时保留内部定位编号。

#### 结果分析

- 顶部指标：累计收益、年化收益、最大回撤、年化波动率、夏普比率、超额收益和换手率。
- 图表：策略与基准净值、回撤、月度收益矩阵、年度收益、持仓数量和行业分布。
- 表格：每日净值、每日持仓、成交记录、个股贡献和行业贡献。
- 分段：上涨、下跌、震荡三个市场阶段，以及用户自选日期区间。
- 所有指标支持查看口径说明。

验收标准：

- 图表、指标和明细使用同一结果数据，不在前端重复计算核心指标。
- 图表上的任一异常日期能够继续查看当日持仓和成交。
- 大型明细采用分页或虚拟列表，页面不因数据量冻结。

#### 研究诊断

- 只基于已生成的指标、图表数据和明细给出解释。
- 每条结论必须标明引用的数据名称与日期范围。
- 诊断包含：表现概览、收益来源、主要拖累、集中度、费用影响、分段稳定性、下一步试验建议。
- 证据不足时明确说明无法判断，不补造数字。
- 用户可以点击引用跳转到相应图表或表格。

验收标准：

- 数字引用与结果记录逐项一致。
- 删除或更换结果后，旧诊断不再显示为当前结论。
- 诊断生成失败不影响用户查看基础回测结果。

#### 策略版本与比较

- 策略详情按时间展示版本历史。
- 版本差异按字段显示旧值和新值。
- 支持选择最多四个版本进行横向比较。
- 比较时展示关键参数、核心指标、净值和回撤。
- 不同数据快照的结果必须显示醒目标记，避免直接误判。

#### 报告

- 输出固定格式的 PDF 报告。
- 内容包括策略摘要、运行假设、数据版本、核心指标、主要图表、诊断和重要说明。
- 报告带生成时间、策略版本和结果编号。
- 首版不提供自由排版。

### 4.2 P1：首版稳定后加入

- 多参数组合试验。
- 自定义指标表达式。
- 团队备注与审批流。
- 两个策略的持仓重合分析。
- 研究模板共享。
- 周频基本面快照分析。

### 4.3 首版明确不做

- 真实资金委托。
- 分钟级或逐笔计算。
- 融资融券、期权和复杂组合。
- 用户提交任意代码并直接运行。
- 公开收益排名和自动跟随。
- 收益承诺、单只股票建议或自动生成买卖结论。

## 5. 主流程

### 5.1 首次研究

1. 用户进入工作台，选择“从想法开始”。
2. 输入策略想法。
3. 研究助手根据缺失项提问。
4. 系统生成规则草案。
5. 用户在结构化表单中检查并确认。
6. 系统执行规则检查。
7. 用户启动回测并查看进度。
8. 任务完成后进入结果页。
9. 用户查看诊断并保存研究记录。

### 5.2 修改后重跑

1. 用户从已有版本选择“创建新版本”。
2. 修改一个或多个字段。
3. 系统展示版本差异。
4. 用户确认后运行。
5. 完成后自动进入版本比较。

### 5.3 参数试验

1. 用户选择一个允许试验的参数。
2. 输入最多十个离散值或一个等距范围。
3. 系统展示预计任务数和资源消耗。
4. 用户确认后批量运行。
5. 结果按稳定性排序，不默认按最高收益排序。

## 6. 状态与异常体验

| 场景 | 产品行为 |
|---|---|
| 尚无策略 | 展示三个常用模板和“从想法开始”入口 |
| 数据尚未准备好 | 禁止启动任务，并显示预计可用时间 |
| 规则不完整 | 定位到具体字段并说明需要补什么 |
| 任务排队 | 显示队列位置和预计开始时间 |
| 任务运行 | 显示阶段进度，允许离开页面 |
| 任务失败 | 保留全部输入，显示原因和重新运行入口 |
| 结果无成交 | 展示筛选过程统计，帮助定位是哪条条件导致 |
| 比较区间不一致 | 默认取共同区间，并允许切换为各自完整区间 |
| 诊断暂不可用 | 基础结果正常展示，提供稍后重试入口 |

## 7. 默认策略模板

首版提供三套模板，模板只预填规则，不预设收益结论：

1. 质量价值：盈利质量、估值和流动性综合排序，月度调整。
2. 趋势强度：中期相对强度排序，月度调整。
3. 低波动：历史波动率排序，月度调整。

每个模板必须展示指标定义、参数默认值、适用限制和数据起始日期。

## 8. 产品指标

| 指标 | 口径 | 首版目标 |
|---|---|---|
| 首次有效回测率 | 新用户首次进入后 24 小时内完成有效回测的比例 | 50% 以上 |
| 15 分钟完成率 | 新用户 15 分钟内完成首次有效回测的比例 | 35% 以上 |
| 任务成功率 | 成功任务数除以已开始任务数 | 98% 以上 |
| 结果复现率 | 固定输入重复运行后结果一致的比例 | 100% |
| 四周留存 | 第四周仍完成至少一次有效研究的用户比例 | 20% 以上 |
| 版本比较使用率 | 保存两个及以上版本的用户中使用比较功能的比例 | 40% 以上 |

“有效回测”定义：规则检查通过、任务成功、存在至少一次成交、结果被保存，且运行区间不少于三个自然年。

## 9. 发布门槛

- P0 验收项全部通过。
- 核心计算基准样例全部通过，金额误差不超过 0.01 元，收益率展示误差不超过 0.01 个百分点。
- 固定输入连续运行三次，结果文件校验值一致。
- 最近十年范围的标准策略在目标计算配置下 60 秒内完成。
- 所有报告都能追溯到策略版本、数据快照和引擎版本。
- 数据商业使用范围已完成书面确认。
