# 回测与指标规范

版本：1.0  
适用引擎：日频多股票组合引擎

## 1. 计算目标

引擎在不使用当时未知信息的前提下，按策略协议逐日计算候选范围、目标组合、成交、持仓、现金和净值，并输出可逐项核对的中间结果。

任何影响金额、持仓或收益的规则都必须在本规范或策略协议中出现，不允许存在隐含默认值。

## 2. 时间约定

- 日期使用交易所当地日期，时间使用 `Asia/Shanghai`。
- 交易日以统一交易日历为准。
- 日线在当日收盘并完成数据校验后视为可用。
- 盘后披露的财务信息最早在下一个交易日的信号计算中使用。
- 信号日为 `T` 时，默认执行日为 `T+1` 的下一个有效交易日。
- 研究区间包括开始日和结束日，预热期不计入展示收益。
- 结果净值以研究区间首个交易日的期初资产归一化为 1。

## 3. 每日计算顺序

每个交易日严格按以下顺序执行：

1. 载入当日交易状态、公司行为和当日开盘信息。
2. 处理除权除息、送转、配股和证券状态变化。
3. 处理之前顺延且仍在有效期内的委托。
4. 在开盘执行当日计划委托，先卖出后买入。
5. 扣减成交费用并更新现金和持仓数量。
6. 使用当日收盘价计算组合收盘市值和净值。
7. 在收盘数据确认后更新指标。
8. 若当日是信号日，计算候选范围、排序和下一执行日目标组合。
9. 写入每日快照和过程统计。

计算顺序是引擎合同的一部分，变更时必须提升引擎版本。

## 4. 信息时间对齐

### 4.1 行情

- 开盘执行只能引用当日开盘价和此前已经完整形成的数据。
- 信号计算可以引用信号日收盘价、成交量和成交额。
- 停牌状态和价格限制使用对应交易日的实际状态字段。
- 当日最终成交量不能用于决定开盘可成交金额；容量依据使用前 20 个完整交易日的平均成交额。

### 4.2 财务信息

- 每条财务记录必须同时保存报告期和首次披露时间。
- 指标在首次披露后的下一个交易日开始可用。
- 更正记录从更正披露后的下一个交易日生效，不回写此前信号。
- TTM 指标使用当时已披露的最近四个单季度值计算。
- 单季度值由累计值推导时，必须保留推导标识。
- 无法可靠推导时记为空，不做零值替代。

### 4.3 股票范围和行业

- 指数成分使用带生效区间的历史成分表。
- 行业分类使用对应日期有效的分类结果。
- 新上市股票在满足最短上市天数后的首个信号日才可进入候选。
- 证券简称变化不改变稳定证券编号。

## 5. 价格与公司行为

### 5.1 两套价格用途

- 成交和持仓估值使用未复权真实价格。
- 收益类指标使用按时间向前连续构建的总收益序列。

总收益序列从每只股票首次可用日以 1 为基准，按当日价格变化、现金分红和送转影响向前递推。递推只使用截至当日已发生的公司行为，避免因未来事件改写过去的指标输入。

### 5.2 现金分红

- 股权登记日收盘持有的数量享有分红。
- 除息日将税后现金计入组合现金。
- 首版采用数据源提供的实际到账金额；没有实际金额时按公布税前金额计算，并在结果中标记估算。

### 5.3 送股与转增

- 在除权日开盘前按比例增加持仓数量。
- 持仓总成本按新增后的数量重新摊薄。
- 因精度产生的零股保留到卖出。

### 5.4 配股

- 首版默认不参与配股，配股权价值不单独计入。
- 报告中必须列出研究区间内持仓遇到的配股事件。
- 后续版本可增加“按现金充足程度参与”的配置。

## 6. 信号计算

### 6.1 候选形成

按以下顺序逐层缩小范围，并保存每层剩余数量：

1. 市场和板块范围。
2. 历史指数成分范围，如有。
3. 上市天数与证券状态。
4. 停牌、价格和流动性条件。
5. 用户筛选条件。
6. 排序字段完整性。

如果最终候选少于目标持仓数量，则持有全部候选，剩余资金保留为现金。

### 6.2 截面处理

- 每个信号日独立计算截面，不把未来日期的分布用于当前日期。
- 缩尾边界使用当前候选截面的 1% 和 99% 分位。
- 百分位排名采用平均名次法。
- 排序方向统一转换为“分数越大越优”。
- 总分保留至少 12 位小数参与排序，界面展示四位。

### 6.3 缓冲名单

为降低边界位置频繁变化，可使用候补缓冲：

- 已持有股票只要仍位于 `目标数量 + 候补数量` 以内，继续保留。
- 空出的名额从最新排名靠前且未持有的股票补足。
- 缓冲只影响换入换出，不改变目标权重算法。

## 7. 目标权重与委托生成

### 7.1 目标权重

- 等权：所有入选股票原始权重相同。
- 按分数：先将非负综合分数归一化；全部为零时退回等权。
- 逆波动：使用截至信号日的 60 个交易日收益波动率倒数归一化；有效样本少于 40 天时排除。

然后依次应用单只权重上限、行业权重上限和现金保留比例。

### 7.2 目标数量

目标市值：

`目标市值 = 信号日组合收盘资产 × 目标权重`

预计买入数量使用执行日基础价估算，并按对应市场最小买入单位向下取整。由于执行日价格可能变化，实际权重允许与目标权重存在偏差。

### 7.3 调整阈值

当 `|目标权重 - 当前权重| < 调整阈值` 时，不生成该股票的调整委托。当前权重按信号日收盘资产计算。

### 7.4 现金约束

- 同日先处理卖出，再根据实际可用现金处理买入。
- 买入资金不足时，按目标缺口金额从大到小分配。
- 每笔买入都必须预留预计费用。
- 不允许现金余额因买入变为负数。

## 8. 成交模型

### 8.1 成交价

基础成交价为执行日开盘价。

- 买入成交价：`开盘价 × (1 + 滑点)`。
- 卖出成交价：`开盘价 × (1 - 滑点)`。
- 成交价按证券价格最小变动单位四舍五入。
- 调整后的成交价不得越过当日有效价格范围；越过时按边界价处理并标记。

### 8.2 可成交判断

出现以下情况时当日不成交：

- 证券全天停牌。
- 缺少可靠开盘价。
- 开盘位于不利方向的价格限制位置，且状态数据表明无法形成有效成交。
- 证券已进入不可交易状态。

未成交委托最多顺延三个交易日。顺延期间每天重新判断状态，但不重新计算目标数量；超过期限后取消，并记录原因。

### 8.3 容量

单只股票单次成交金额上限：

`前 20 个完整交易日平均成交额 × 最大参与比例`

超过上限时只成交允许部分，剩余部分不继续顺延。平均成交额有效天数不足 15 天时，当日不新增该股票持仓，但允许卖出。

### 8.4 最小交易单位

- 买入数量向下取整到对应证券的最小单位。
- 正常卖出按可卖数量处理。
- 因公司行为形成的零股允许随整笔卖出处理。

## 9. 费用计算

每笔成交独立计算费用：

`佣金 = max(成交金额 × 佣金率, 最低佣金)`

`法定税费 = 成交金额 × 成交日期对应费率`

`总费用 = 佣金 + 法定税费 + 过户费用`

规则：

- 佣金买卖双边收取。
- 法定税费按对应日期和方向收取。
- 过户费用按对应日期和市场收取。
- 所有费用以分为最小单位四舍五入。
- 费率表包括生效日、失效日、市场、方向和费率来源说明。

## 10. 特殊证券状态

### 10.1 长期停牌

- 持仓继续按最近可用收盘价估值，并在结果中标记价格陈旧天数。
- 目标卖出无法执行时继续持有，但最多只保留三日委托；之后等待下次调仓重新生成。
- 价格陈旧超过 20 个交易日时，结果页必须显示醒目提示。

### 10.2 终止上市

- 在最后可交易阶段按策略正常尝试卖出。
- 若最终仍持有，优先使用数据源提供的最终结算价值。
- 没有可靠结算价值时，以 0 计值，并在报告中单独列示金额影响。
- 不允许使用删除该证券样本的方式处理。

### 10.3 数据缺口

- 单日收盘价缺失且确认停牌时，使用最近有效收盘价估值。
- 原因不明的关键行情缺失时，任务停止并进入失败状态。
- 非关键展示字段缺失不阻止运行，但结果中记录缺失比例。

## 11. 资产与收益计算

### 11.1 每日资产

`股票市值_t = Σ(持仓数量_i,t × 收盘价_i,t)`

`总资产_t = 现金_t + 股票市值_t + 当日应收现金_t`

`净值_t = 总资产_t / 研究首日期初总资产`

### 11.2 日收益

`r_t = 总资产_t / 总资产_(t-1) - 1`

首日收益以研究首日期初资产为基准。用户追加或取出资金不在首版范围内。

## 12. 指标定义

一年交易日数固定取 252。展示百分比保留两位小数，底层计算不提前截断。

### 12.1 累计收益

`累计收益 = 期末净值 / 期初净值 - 1`

期初净值固定为 1。

### 12.2 年化收益

`年化收益 = (期末净值 / 期初净值)^(252 / 有效交易日数) - 1`

有效交易日少于 60 时不展示年化收益，只展示累计收益。

### 12.3 年化波动率

`年化波动率 = 日收益标准差 × sqrt(252)`

标准差使用样本标准差，分母为 `n - 1`。

### 12.4 夏普比率

`夏普比率 = (日收益均值 - 日无风险收益) / 日收益标准差 × sqrt(252)`

- 默认年化无风险收益为 2%，可在研究设置中修改。
- 日无风险收益由年化值按复利换算。
- 日收益标准差为 0 时不展示。

### 12.5 最大回撤

`回撤_t = 净值_t / 截至 t 的历史最高净值 - 1`

最大回撤是研究区间内回撤的最小值，同时输出：

- 高点日期。
- 最低点日期。
- 再次达到此前高点的日期。
- 从高点到最低点的交易日数。
- 从最低点到恢复的交易日数；尚未恢复时显示“未恢复”。

### 12.6 超额收益

策略与基准在同一日期归一化：

`超额净值_t = 策略净值_t / 基准净值_t`

`累计超额收益 = 超额净值_期末 - 1`

### 12.7 信息比率

`主动收益_t = 策略日收益_t - 基准日收益_t`

`信息比率 = 主动收益均值 / 主动收益样本标准差 × sqrt(252)`

主动收益标准差为 0 时不展示。

### 12.8 胜率

页面同时提供两个明确名称，避免口径混淆：

- 月度胜率：收益大于 0 的完整自然月数量除以完整自然月总数。
- 成交批次胜率：已完成卖出的持仓批次中，扣除费用后收益大于 0 的批次数除以全部已完成批次数。

跨多个买入批次的卖出按先进先出方法匹配成本。尚未卖出的持仓不计入成交批次胜率。

### 12.9 盈亏比

`盈亏比 = 盈利批次平均盈利金额 / |亏损批次平均亏损金额|`

没有盈利批次或没有亏损批次时不展示。

### 12.10 换手率

单日双边换手率：

`换手率_t = (当日买入金额 + 当日卖出金额) / (2 × 当日日均总资产)`

`当日日均总资产 = (前一日总资产 + 当日总资产) / 2`

年化换手率为日换手率均值乘以 252。首日使用当日期初资产替代前一日资产。

### 12.11 持仓集中度

- 前五大持仓占比：收盘时权重最大的五只股票权重之和。
- 个股集中度：所有股票权重平方和。
- 行业集中度：所有行业权重平方和。

现金不计入集中度公式，但单独展示现金占比。

### 12.12 贡献

个股单日贡献：

`前一日收盘权重 × 个股当日总收益率`

交易费用作为独立贡献项，不分摊到个股。行业贡献为行业内个股贡献之和。所有贡献项加总后应与组合日收益保持一致，允许的浮点差异不超过 `1e-10`。

## 13. 月度与年度统计

- 月度收益使用月末净值相对上月末净值计算。
- 研究首月使用研究首日期初净值作为基准。
- 研究末月即使不完整也展示，并标明“非完整月份”。
- 年度收益同理，非完整年度明确标记。
- 月度矩阵缺少完整数据时显示空值，不显示 0。

## 14. 市场阶段分段

首版按比较基准的 120 日移动平均趋势和 60 日波动率划分：

- 上涨阶段：基准收盘高于 120 日均线，且均线近 20 日斜率为正。
- 下跌阶段：基准收盘低于 120 日均线，且均线近 20 日斜率为负。
- 震荡阶段：其余日期。

分段标签只用于事后分析，不参与策略信号。每一段分别计算累计收益、年化收益、波动率、最大回撤和相对基准表现。

## 15. 输出数据集

每次成功运行至少保存：

| 数据集 | 最小字段 |
|---|---|
| 每日资产 | 日期、现金、市值、总资产、净值、日收益、基准净值 |
| 每日持仓 | 日期、证券编号、数量、成本、收盘价、市值、权重、行业 |
| 成交记录 | 委托编号、日期、证券编号、方向、数量、价格、金额、各项费用、原因 |
| 信号快照 | 信号日、候选数量、各层筛选数量、入选编号、分数、目标权重 |
| 指标结果 | 指标编号、数值、单位、口径版本、开始日、结束日 |
| 事件记录 | 日期、事件类型、证券编号、处理结果和金额影响 |

## 16. 一致性要求

- 每日满足：现金 + 股票市值 + 应收现金 = 总资产。
- 每笔成交满足：数量 × 价格 = 成交金额，允许的金额舍入误差不超过 0.01 元。
- 每日持仓变化能够由前一日持仓、成交和公司行为完整解释。
- 个股贡献、费用贡献与现金贡献之和能够解释组合收益。
- 相同输入重复运行时，所有正式输出文件的校验值一致。

## 17. 基准测试样例

开发前必须建立并人工核对以下固定小样本：

1. 单只股票买入并持有十个交易日。
2. 两只股票等权，每月调整一次。
3. 存在现金分红和送转。
4. 执行日停牌并顺延。
5. 触及价格限制导致未成交。
6. 最低佣金对小额成交产生影响。
7. 研究区间跨越法定费率变化日。
8. 持仓证券终止上市且没有可靠结算价值。
9. 候选数量少于目标持仓数量。
10. 行业上限使部分资金保留为现金。

每个样例都要固定输入表、逐日手算表和预期输出，作为引擎升级时的回归基线。
